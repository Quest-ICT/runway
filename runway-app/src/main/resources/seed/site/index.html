Three things worth doing first

A short, deliberate setup beats a long one. These are the changes that make the biggest difference to how your site reads and how it is found.

01

Write a real title and description

Every page carries its own. They are what a search engine shows, what appears when someone shares the link, and often the only thing a visitor reads before deciding to click. Write them for a person, not for a keyword.

02

Make the words yours

Replace this placeholder copy with something only you could have written — what you actually do, for whom, and why it is different. Specific beats polished, and it is the one thing no template can supply.

03

Adjust the look

The colours, spacing and typefaces live in one block at the top of the master template. Change a handful of values there and every page follows, because they all share this same chrome.

This page and the About page share one master template. Edit the master and both change together; edit a page and only that page changes. Add as many pages as you like — each new one is born from the same master, so the header, footer and styling stay consistent without you repeating yourself.
