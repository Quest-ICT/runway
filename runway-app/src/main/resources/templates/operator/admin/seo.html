Uploaded documents

Sends X-Robots-Tag: noindex with every file under /static/doc/. A PDF has no page markup, so this header is the only way to ask a search engine not to list it. It applies to all of them together, and only to engines that honour it — it is not access control: the files stay publicly downloadable to anyone with the link.

Extra <head> markup

Injected verbatim into every page's <head>. For trusted markup only (link tags, structured-data scripts) — it is not escaped.
