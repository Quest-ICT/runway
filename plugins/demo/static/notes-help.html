Runway Demo — help

This page is a static asset served from the plugin's own namespace at /__plugin/runway-demo/static/notes-help.html. Runway Demo is the reference plugin: everything it does is there to show plugin authors how a feature is built.

The demo screen

The Runway demo entry of the console menu opens the plugin's own screen (it needs the manage-notes permission). From there you can add notes, install a ready-made demo page, publish a short showcase page, look at the site's published content and check whether a path is free, and see the changes the plugin has been told about.

Notes

The demo keeps a small set of per-site notes in its own folder of the site. Notes are:

  • seeded with a welcome note the first time a site's notes are read;
  • added from the demo screen, and by visitors through the public feedback form;
  • appended automatically whenever this plugin's per-site settings are saved;
  • readable as JSON at /demo/notes.json — only with the manage-notes permission (anyone else gets 403);
  • kept in full backups, and left out of transfer copies: they hold what people typed, so the plugin declares them personal data.

Pages and endpoints

  • /demo — the demo page, once installed from the demo screen. It is an ordinary site page: edit, move or delete it under Pages.
  • /demo/showcase — the showcase page, while one is published.
  • /demo/hello.txt — a per-site greeting in the visitor's language.
  • /demo/echo.json — echoes what the platform tells the plugin about your request.
