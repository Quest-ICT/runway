Carousel — help & reference

The Carousel Manager plugin adds a configurable image/slide carousel you can place on any page.

1. Configure the slides

On the carousel settings page, fill Slides — one slide per line, fields separated by a pipe (|):

/static/img/hero1.jpg | Welcome to Acme | /about
/static/img/hero2.jpg | Our latest work  | /work
/static/img/hero3.jpg

Only the image URL is required; the caption and the click-through link are optional. Other settings: the auto-advance interval (seconds; 0 disables auto-play), whether to show captions, and whether to show the previous/next controls.

2. Place the carousel on a page

Add an anchor where the carousel should appear (the id and data-widget must be on the same element):

<div id="hero" data-widget="carousel/hero"></div>

The widget renders your configured slides there, pulling in its own stylesheet and script automatically. With no slides configured it renders nothing.

Note: one carousel per site (for now)

This plugin does not yet declare a per-placement widget configuration (Runway supports one), so every carousel/* anchor on a site shows the same configured slides. Distinct carousels per page need that declaration in a later version — the widget already carries the instance id for it.
