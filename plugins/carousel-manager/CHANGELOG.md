# Changelog

All notable changes are recorded here. Versions follow [Semantic Versioning](https://semver.org/).

## [2.1.0] — 2026-10-21

First public release of `carousel-manager`: an image/slide carousel content widget — slides configured per site,
placed on any page with a `data-widget` anchor; self-contained CSS and JavaScript, no external libraries. Requires SPI `1.0.0` (Runway `1.0.0` or later). Licensed under the GNU AGPL v3.0 with an additional permission for
plugins (`LICENSE`, `LICENSE-EXCEPTION`).
