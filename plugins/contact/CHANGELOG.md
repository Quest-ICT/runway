# Changelog

All notable changes are recorded here. Versions follow [Semantic Versioning](https://semver.org/).

## [2.1.0] — 2026-10-21

First public release of `contact`: an embeddable contact-form widget whose submissions are both emailed over the
site's own SMTP relay and stored as site data for the console, with CAPTCHA (when the site has one) and a
honeypot against spam. Requires SPI `1.0.0` (Runway `1.0.0` or later). Licensed under the GNU AGPL v3.0 with an additional permission for
plugins (`LICENSE`, `LICENSE-EXCEPTION`).
