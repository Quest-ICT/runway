# Changelog

All notable changes are recorded here. Versions follow [Semantic Versioning](https://semver.org/).

## [10.4.0] — 2026-10-21

First public release of `lucene-provider`: one deployment-wide copy of Apache Lucene 10.4.0 for the plugins that use
it (`search-lucene`). Its version is the Lucene version it ships. The plugin's packaging is licensed under the GNU
AGPL v3.0 with an additional permission for plugins (`LICENSE`, `LICENSE-EXCEPTION`); the bundled Lucene jars stay
under the Apache License 2.0, each with its own LICENSE and NOTICE.
