# Changelog

All notable changes are recorded here. Versions follow [Semantic Versioning](https://semver.org/).

## [2.3.0] — 2026-10-21

First public release of `discoverability`: SEO and GEO for Runway sites — `/sitemap.xml`, `/robots.txt`
(including groups for AI crawlers), `/llms.txt` and schema.org JSON-LD from one shared core, adding only what the
kernel's own SEO leaves out. Requires SPI `1.0.0` (Runway `1.0.0` or later). Licensed under the GNU AGPL v3.0 with an additional permission for
plugins (`LICENSE`, `LICENSE-EXCEPTION`).
