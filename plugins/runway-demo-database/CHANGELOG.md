# Changelog

All notable changes are recorded here. Versions follow [Semantic Versioning](https://semver.org/).

## [1.0.0] — 2026-10-29

First public release of `runway-demo-database`: a per-site guestbook on the `database` plugin, the worked example of
a plugin that keeps its data in the database (migrations for both products, transactions, the site's CAPTCHA on a
public form, backup and restore). Requires SPI `1.1.0` (Runway `1.1.0` or later) and `database` `1.0.0`. Licensed
under the Apache License 2.0 (`LICENSE`, `NOTICE`), so a plugin started from a copy of it may carry any license.
